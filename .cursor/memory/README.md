# Coding-agent memory

Markdown bank for Cursor sessions working on jaha-eye. **Not** the product's future session store.

## Files

- `project.md` — current phase, stack, in/out scope
- `decisions.md` — dated decision log (what, why)
- `glossary.md` — agent, run, event, control plane, data plane

## Usage

- Read `project.md` at session start.
- Record stack/boundary decisions with the `record-project-memory` skill.
- **Never store secrets or API keys here.**
