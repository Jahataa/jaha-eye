# UI documentation

React SPA in `apps/web`. Operator console — not a chat app.

## Topics

- [screens.md](screens.md) — routes and what each screen shows
- [state.md](state.md) — TanStack Query, Zustand, SSE
- [components.md](components.md) — layout and feature components

## Stack

Vite, React 19, TypeScript, React Router, TanStack Query, Zustand, Tailwind CSS, shadcn-style components.

## Dev

```bash
npm run dev -w @jaha-eye/web
```

Default: http://localhost:5173 (proxies `/api` to :4000)
